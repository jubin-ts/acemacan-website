# ACEMACAN FZ LLC — Company Website

A modern, elegant single-page website for **ACEMACAN FZ LLC**, a UAE-based Free Zone company.

## About ACEMACAN

ACEMACAN FZ LLC specializes in:

- **General Trading** — Import & Export across international markets
- **MEP Equipment** — Mechanical, Electrical & Plumbing supplies
- **Fire & Safety** — Certified fire protection and safety systems
- **HSE Equipment** — Health, Safety & Environment solutions
- **ACE Acoustics** (sub-brand) — Premium acoustic panels, insulation, and noise-control products
- **Global Sourcing & Logistics** — End-to-end procurement and supply chain
- **Digital Services** — Website Development, SEO, Digital Marketing, Branding & Profile Optimization

## Tech Stack

- Pure **HTML5** & **CSS3** — no frameworks, no build tools
- Responsive design (mobile, tablet, desktop)
- Google Fonts (Inter)
- Smooth scroll, hover animations, CSS transitions

## Project Structure

```
├── index.html      # Single-page website (all sections)
├── css/
│   └── style.css   # All styles, animations, responsive rules
└── README.md
```

## How to Run

Simply open `index.html` in any modern browser. No server or build step needed.

## Logo

The ACEMACAN logo is loaded from a hosted URL. To use a local copy, place the logo as `images/logo.png` and update the `src` attributes in `index.html`.
